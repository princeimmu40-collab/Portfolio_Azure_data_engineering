Professional Summary

Four years deep in the Azure data ecosystem

I build and maintain data platforms for healthcare claims processing, working primarily inside the Microsoft Azure ecosystem — Azure Data Factory, Logic Apps, and SQL Server. Most of my work centers on Molina Healthcare's QNXT claims platform: migrating claims data out of legacy systems, mapping it into new architectures, and making sure every record that moves is validated and reconciled before it reaches production.

Alongside day-to-day pipeline and performance-tuning work, I've been self-directed in upskilling into Azure Databricks and PySpark, extending my SQL Server background into distributed, big-data processing patterns — because legacy-to-cloud migration is only getting bigger, not smaller.
